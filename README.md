# .github

Organization-level configuration and the public profile for [Void Projects](https://github.com/voidprojectssoftware).

- **[`profile/README.md`](./profile/README.md)** — the org profile shown on our GitHub landing page.
- **[`profile/assets/void-hero.svg`](./profile/assets/void-hero.svg)** — the animated hero, generated from real NASA/JPL HORIZONS spacecraft trajectory data.
- **[`scripts/generate-hero.mjs`](./scripts/generate-hero.mjs)** — regenerates the hero SVG. Run `node scripts/generate-hero.mjs`.
